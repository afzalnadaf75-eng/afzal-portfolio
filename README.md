## 🌟 Overview

An award-winning personal developer portfolio designed and built for **Afzal Nadaf**. Crafted with a deep cosmic design language, Apple-inspired visual polish, and interactive creative development techniques inspired by Awwwards websites.

### Key Experience Features

- 🌌 **Interactive Cosmic Starfield Engine**:
  - HTML5 Canvas with 3D z-depth perspective projection.
  - 7 interactive mouse & touch physics modes:
    1. *Gravitational Attraction* (particles gently curve towards cursor)
    2. *Magnetic Orbit* (stars gently orbit cursor)
    3. *Movement Disturbance* (rapid mouse flick creates shockwave flutter)
    4. *Constellation Effect* (delicate glowing lines connect nearby stars and cursor)
    5. *Cursor Particle Trail* (stardust following cursor motion)
    6. *Cosmic Ripple* (clicks trigger an expanding shockwave pushing particles with elastic recovery)
    7. *Natural Drift & Twinkle* (autonomous celestial movement)

  - Zero click interference (`pointer-events-none` on canvas).

- 🚀 **Cinematic Welcome Screen & Warp-Speed Hyperspace Transition**:
  - Full-screen entrance awakening from deep cosmic black.
  - Phased typography animation sequence with telemetry status.
  - Interactive `[ ENTER THE UNIVERSE ↗ ]` button with radiant glow.
  - Hyperspace warp-speed acceleration streaking stars radially with smooth zoom into the portfolio hero.
  - "Skip Intro" option for immediate access.

- ⚡ **Interactive Developer Terminal (CLI)**:
  - Accessible via the navbar `[ CLI ]` button or floating commands.
  - Authentic terminal experience with commands:
    `help`, `about`, `skills`, `projects`, `journey`, `contact`, `github`, `warp`, `clear`, `date`, `whoami`, `exit`.
  - Supports command history (Up/Down arrow keys) and tab autocompletion.

- 🔊 **Synthesized Web Audio Engine**:
  - Zero external MP3/WAV dependencies; uses pure programmatic Web Audio API synthesis.
  - Subtle futuristic UI clicks, warp-drive whoosh, harmonic entrance chimes, and terminal blips.
  - Global mute/unmute toggle in the navbar.

## 🚀 Getting Started

### 1. Set as Active Workspace
To work with this project in Antigravity, open folder:
```
C:\Users\AFZAL\.gemini\antigravity\scratch\afzal-portfolio
```

### 2. Development Server
Run the local Vite development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
Verify or create a production-ready bundle:
```bash
npm run build
```
Preview the built bundle:
```bash
npm run preview
```

## 🎨 Customizing Content

All personal content is centralized in a single configuration file for instant editing:
📂 `src/data/portfolioData.ts`

- **LinkedIn URL**: Replace `https://linkedin.com/in/afzal-nadaf` with your actual profile link.
- **Email**: Update `afzalnadaf.dev@gmail.com` to your preferred contact address.
- **Profile Photograph**: Replace the placeholder avatar in `src/components/about/AboutSection.tsx` with your image by adding an image file (e.g., `src/assets/profile.jpg`) and importing it.
- **Projects**: Update demo URLs or add repository links in `PROJECTS_DATA`.
